# hbx-invoice-generator

# Privacy policy
Last updated: 23 October 2026

Hbx Invoice Sender is a personal tool operated by its sole user, Maximiliano de Almeida Carvalho. It is not offered to the public.

Data accessed
With the user's consent, the tool accesses Google Drive, Google Docs and Gmail through Google's APIs in order to copy and edit an invoice document, export it as PDF and create an email draft in the user's own account.

Data storage and sharing
OAuth tokens are stored encrypted on the user's own computer. Exported PDFs are written to the user's local disk. No data is sent to any third party, no analytics are collected, and nothing is stored on any server operated by the author.

Google API Services User Data Policy
Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
